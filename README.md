# Arcade

A collection of early **Python game experiments** and a Pygame launcher.

**Historical personal project · 2019 · Python / Pygame / Tkinter / NumPy**

## Included experiments

The repository contains implementations of Snake, Pong, a Flappy Bird-style game, a Pac-Man-style game, Connect Four, Tic-Tac-Toe, and an anti-Tic-Tac-Toe variant. `Arcade.py` provides a graphical launcher for a subset of them.

## Reading and running

Start with an individual game file to follow its game loop, state, collision or win logic, and input handling. The launcher and several games expect a Windows-style `Games` / `sprites` directory layout that differs from the committed flat structure. Asset paths, exit handling, and per-game dependencies need repair before a complete launcher demo is supported.

This README does not claim every game or asset was independently authored. Provenance and licenses should be checked before redistributing the collection or publishing a new build. No new asset license is applied by this documentation refresh.
